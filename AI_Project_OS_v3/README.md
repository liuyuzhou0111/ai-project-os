# AI Project OS v3

个人知识资产与 AI 协作系统。

## 目标

- 保存长期有效的个人上下文与工作方法
- 沉淀项目背景、核心判断、决策演进与方法论
- 让不同 AI 在读取知识库后快速接手工作
- 避免重要认知仅存在于聊天记录中

## 目录

- `00_Context/`：个人背景、AI 协作方式与使用说明
- `01_Projects/民宿信息产品力/`：核心项目知识
- `02_Methodology/`：可复用方法论
- `03_Decision_Log/`：关键决策与演进
- `99_System/`：知识库维护规则

> v2 保留作为早期系统框架探索版本；v3 重点转向“个人知识资产 + 持续协作”。
